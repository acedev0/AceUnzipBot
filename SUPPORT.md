# Support

For setup and runtime problems:

1. Run `aceunzip doctor`.
2. Read [Troubleshooting](docs/TROUBLESHOOTING.md) and [Deployment](docs/DEPLOYMENT.md).
3. Search GitHub issues.
4. Open a bug report with sanitized logs if the problem remains.

Never post API hashes, bot tokens, `.env`, Telethon sessions, archive passwords, private channel
IDs, or user archives. Security reports belong in the private process described by
[SECURITY.md](SECURITY.md).
